# Echos of the Dark Flute

> A 2D action-RPG dungeon crawler built with the Godot Engine.  
> Developed as part of **CP3407 – Advanced Software Engineering**.

---

## 🛠️ Setup & Installation

1. Download and install the [Godot Engine](https://godotengine.org/)
2. Clone or download this repository
3. Open Godot and select **Import Project**
4. Navigate to the project folder and select `project.godot`
5. Press **Run** to start the game

> ⚠️ Make sure the `project.godot` file remains intact in the root folder.

---

## 🎮 Controls

| Key | Action |
|-----|--------|
| `W A S D` | Movement |
| `E` | Attack |
| `F` | Interact |
| `Shift` | Dash |
| `Q` | Use ability / item |
| `Tab` | Cycle ability / item |
| `Esc` | Pause menu |

---

## 📖 How to Progress

1. **Talk to NPCs** to receive and begin the quest
2. **Travel to the dungeon**, defeating enemies along the way to level up
3. Inside the dungeon, **solve puzzles** using mechanisms and abilities you unlock
4. **Defeat the boss**
5. **Return to the quest-giver NPC** to complete the game
